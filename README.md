## <a id="title1">1. Цель и суть проекта</a>
Реализовать программу, которая с помощью API будет получать информацию о компаниях и вакансиях с платформы HeadHunter (возможно использовать с другими аналогичными ресурсами по поиску работы), загружать и сохранять результаты поиска в в спроектированные таблицы в БД PostgreSQL и позволять удобно работать с ними (пользовательские запросы на получение отфильтрованных данных).

### Функциональный код разбит на:
1. `Получение данных с API`
   - Получение данных о работодателях и их вакансиях с сайта *hh.ru* (для этого используем публичный API HeadHunter и библиотека *requests*).
   - Выбор не менее 10 компаний по которым будем получать данные о самих компаниях и их вакансиях.
2. `Взаимодействие с json-файлами`
   - Создание json-файла для хранения информации о выбранных организациях (работодатели).
   - Создание json-файла для хранения информации о вакансиях выбранных компаний.
3. `Создание базы данных PostgreSQL и её структурирование`
   - Спроектированы таблицы в БД *PostgreSQL* для хранения полученных данных о работодателях и их вакансиях. Для работы с БД используется библиотека *psycopg2*.
4. `Загрузка данных в БД`
   - Реализован код, который заполняет созданные таблицы в БД *PostgreSQL* данными о работодателях и их вакансиях.
5. `Разработка класса DBManager для работы с данными`
   - Создан ***class DBManager*** для работы с данными в БД.
   - Класс DBManager будет подключаться к БД PostgreSQL и иметь следующие методы:
     - **get_companies_and_vacancies_count()** — получает список всех компаний и количество вакансий у каждой компании.
     - **get_all_vacancies()** — получает список всех вакансий с указанием названия компании, названия вакансии и зарплаты и ссылки на вакансию.
     - **get_avg_salary()** — получает среднюю зарплату по вакансиям.
     - **get_vacancies_with_higher_salary()** — получает список всех вакансий, у которых зарплата выше средней по всем вакансиям.
     - **get_vacancies_with_keyword()** — получает список всех вакансий, в названии которых содержатся переданные в метод слова, например python.
6. `Создание интерфейса для взаимодействия с пользователем`
   - "точка входа" - модуль, запустив который пользователь программы сможет получить данные о вакансиях с помощью реализованных методов.
7. `Модуль со вспомогательными функциями`
   - Например, функция получения курсов валют. Так как вакансии на hh.ru могут быть в разных валютах, а для корректной работы таких методов, как get_avg_salary() и другие, необходим перевод к общей валюте.

### Документация для сбора вакансий с hh.ru:
  - Ссылка на API: https://github.com/hhru/api/.

### Выходные данные:
   - Вывод пользователю в консоли отфильтрованных и отсортированных данных о вакансиях и работодателях.



  
## <a id="title2">2. Основные модули / функции</a>

## <a>src/api/</a>

#### Абстрактные классы:
1. ***abs_base_employer_api.py*** - модуль содержит код абстрактного класса `BaseEmployersAPI(ABC)` для работы с API работодателей.
   - Абстрактный класс содержит следующие *@abstractmethod*:
      - **get_employer_id()**: абстрактный метод для поиска ID работодателей по заданному пользователем перечню названий работодателей.

2. ***abs_base_vacancies_api.py*** - модуль содержит код абстрактного класса `BaseVacanciesAPI(ABC)` для работы с API вакансий.
   - Абстрактный класс содержит следующие *@abstractmethod*:
      - **get_vacancies()**: абстрактный метод для поиска вакансий по ID работодателей.

3. ***abs_base_area_api.py*** - модуль содержит код абстрактного класса `BaseAreasAPI(ABC)` для работы с API регионов/городов.
   - Абстрактный класс содержит следующие *@abstractmethod*:
      - **get_area_ids()**: абстрактный метод для поиска ID регионов/городов.

#### Базовые классы:
1. ***base_headhunter_api.py*** - модуль содержит код базового класса `HeadHunterBaseAPI()` для работы с API сервиса HeadHunter.
   - Класс содержит следующие методы:
     - **__init__(api_name_service)**: конструктор для инициализации подключения к API сервису.
       - *:param api_name_service*: значение 'employers' или 'vacancies' для формирования url сервиса HeadHunter.
     - **_make_request(params)**: метод для выполнения GET-запросов.
       - *:param params*: параметры запросов (либо для 'employers', либо для 'vacancies').

#### Наследники базовых классов:
1. ***hh_employer_api.py*** - модуль содержит код класса-наследника `HeadHunterEmployersAPI(HeadHunterBaseAPI, BaseEmployersAPI)` для поиска ID работодателей по заданному пользователем перечню названий работодателей.
   - Класс содержит следующие методы:
     - **__init__()**: конструктор для инициализации подключения к API работодателей (api_name_service = employers).
     - **get_employer_ids(employer_names)**: метод для выполнения GET-запроса поиска ID работодателя по его названию.
       - *:param employer_names*: данные настроек пользователя с перечнем названий работодателей.
       - *:return*: список ID работодателей.

2. ***hh_vacancy_api.py*** - модуль содержит код класса-наследника `HeadHunterVacanciesAPI(HeadHunterBaseAPI, BaseVacanciesAPI)` для поиска вакансий по переданному списку ID работодателей.
   - Класс содержит следующие методы:
     - **__init__()**: конструктор для инициализации подключения к API вакансий (api_name_service = vacancies).
     - **get_vacancies(employer_ids)**: метод для выполнения GET-запроса поиска вакансий.
       - *:param employer_ids*: список ID работодателей.
       - *:param area_ids*: список ID регионов/городов.
       - *:return*: список всех вакансий по запрашиваемым работодателям.

3. ***hh_area_api.py*** - модуль содержит код класса-наследника `HeadHunterAreasAPI(HeadHunterBaseAPI, BaseAreasAPI)` для поиска ID городов по заданному пользователем перечню названий городов.
   - Класс содержит следующие методы:
     - **__init__()**: конструктор для инициализации подключения к API регионов/городов (api_name_service = areas).
     - **get_area_ids(area_names)**: метод для выполнения GET-запроса поиска ID городов по их названию.
       - *:param area_names*: список городов, заданных пользователем.
       - *:return*: список ID городов.




## <a id="title3">3. Вспомогательные модули / функции</a>

## <a>src/</a>

1. ***src/get_employers_name.py*** - модуль содержит код функции `get_employer_names_for_search(path_to_file)`, которая:
   - Cчитывает из json-файла заданный по умолчанию пользовательский перечень работодателей (10 компаний) для дальнейшего поиска и сбора всех вакансий по указанным в файле компаниям.
   - Если пользовательских настроек нет, то возвращается пустой список, который потом, с помощью функции пользовательского взаимодействия user_interaction() в main.py, будет заполняться/наполняться самим пользователем.
   - Параметры функции:
     - *:param path_to_file*: путь к json-файлу с пользовательскими настройками.
     - *:return*: Перечень названий работодателей в формате dict.




## <a id="title4">4. Взаимодействие пользователя с программой (модуль *main.py*)</a>
Модуль `main.py` содержит код для функции `user_interaction()` - это функция для взаимодействия пользователя с программой, которая позволяет ему:
1. Выбрать платформу для поиска вакансий (например, сейчас это только "HeadHunter", но можно расширить другими сервисами);
2. Указать вариант выборки вакансий:
   - по заданному списку работодателей (10 компаний).
   - дополнить заданный список работодателей какими-то новыми дополнительными компаниями (10+).
   - задать свой собственный список работодателей (игнорировать заданный в программе список).
